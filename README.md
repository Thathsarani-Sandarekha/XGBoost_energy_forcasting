# ⏰ Time Series Forecasting with XGBoost

This project predicts hourly energy consumption using XGBoost. It includes time-based feature engineering, lag features, time series cross-validation, and future forecasting.

---

## 📁 Features

- Time-based feature engineering (hour, day, month, etc.)
- Lag features for yearly seasonality
- TimeSeriesSplit cross-validation
- XGBoost model training and evaluation
- Future forecasting for 1 year
- Model saving and reloading
- CSV output for Power BI dashboards

---

## 📂 Dataset

- **Name:** Hourly Energy Consumption
- **Source:** [Kaggle – robikscube](https://www.kaggle.com/datasets/robikscube/hourly-energy-consumption/data)
- **File Used:** `PJME_hourly.csv`
